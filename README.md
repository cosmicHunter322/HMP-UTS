Daftar fitur yang berhasil di implementasi:

- Halaman Dashboard Penjualan: Menampilkan ringkasan informasi harian seperti total produk, transaksi hari ini, dan produk terlaris.
- Navigasi Tab Bawah: Menu navigasi mencakup dashboard, produk, transaksi, dan profil.
- Daftar Produk dan Pencarian Real-Time: Menyediakan kolom pencarian barang serta daftar produk lengkap dengan informasi stok, kategori, dan harga.
- Keranjang Belanja dan Konfirmasi Transaksi: Fitur keranjang yang menghitung total belanja secara otomatis beserta tombol konfirmasi transaksi.
- Riwayat Transaksi: Menu pencatatan riwayat transaksi yang menampilkan ID transaksi, waktu, dan nominal total penjualan.
- Form Tambah/Edit Produk: Formulir input data produk terstruktur yang mencakup nama produk, harga beli, harga jual, stok, kategori, dan URL gambar.
- Detail Produk: Halaman rincian barang untuk melihat informasi lengkap dari produk.
- Pengaturan Tema: Fitur untuk beralih antara mode gelap (dark theme) dan mode terang (light theme) di menu pengaturan.
- Arsitektur Angular Service: Pemisahan logika data menggunakan service untuk cart, produk, dan transaction.
- Property & Event Binding: Menerapkan binding untuk menampilkan gambar default jika foto produk belum tersedia, mendisable tombol tambah ke keranjang secara otomatis jika stok habis (0), serta menangani aksi klik tombol.
- Animasi: Efek animasi ringan saat perpindahan halaman dan foto profil.
